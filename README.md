# Spam_Message_detection
# 📩 Spam Message Detection using Machine Learning

This project is focused on building a machine learning model to classify SMS messages as **spam** or **ham (not spam)** using Natural Language Processing (NLP) techniques and various classification algorithms.

## 🚀 Features

- Preprocessing of SMS text data
- Vectorization using TF-IDF
- Training multiple classifiers (Naive Bayes, SVM, Logistic Regression, etc.)
- Evaluation of model performance (accuracy, precision, recall, F1-score)
- Streamlit web app for interactive spam message detection

## 🧠 Algorithms Used

- Multinomial Naive Bayes
- Logistic Regression
- Support Vector Machine (SVM)
- Random Forest Classifier

## 📊 Dataset

The dataset used is the **SMS Spam Collection Dataset**, which contains 5,574 messages tagged as **spam** or **ham**. It is a widely used benchmark dataset for spam detection.

Dataset columns:
- `label`: Indicates whether the message is "ham" or "spam".
- `message`: The actual text of the SMS message.

## 🛠️ Technologies Used

- Python
- Pandas, NumPy
- Scikit-learn
- NLTK
- Streamlit
- Matplotlib / Seaborn (for visualization)
